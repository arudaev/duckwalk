A preview of Duckwalk v0.1, so you can install it without building anything: Harold, a rubber debugging duck on your Flipper Zero, keeps your computer awake and works as its remote.

**This is a pre-release.** It is the same app as v0.1 will be, with two things still open: Duckwalk isn't in the Flipper Apps Catalog yet, and its USB ID (`1209:D0C4`) is still waiting for [pid.codes](https://github.com/pidcodes/pidcodes.github.com/pull/1353) to approve it. If pid.codes gives it another number, the next preview changes it, and you'd update both the Flipper app and the desktop app.

## Since v0.1-rc1

- **The desktop app is lighter:** it waits for news instead of checking all the time, so it wakes up about half as often while you're away, and about a third less while you work. Update it if you have rc1's.
- **The Flipper app is the same** as in v0.1-rc1. If you have it, there's no need to copy it again.
- **You can check where each file was built:** see the end of the Install section.

## Install

1. **Update the Flipper first** to the latest official firmware, 1.5.1 or newer, with qFlipper or the Flipper mobile app. This `duckwalk.fap` is built for firmware 1.5.1 (API 88.2); on older firmware the Flipper says **Outdated Firmware**.
2. **Flipper app:** download `duckwalk.fap` below. Open qFlipper, go to the file manager, open **SD Card > apps > USB** and drag `duckwalk.fap` into it. On the Flipper: **Apps > USB > Duckwalk**.
3. **Desktop app (optional):** it tells Harold when you're at the computer.
   - **Windows:** `duckwalk-desktop-windows-x64.exe` (most PCs) or `duckwalk-desktop-windows-arm64.exe` (Windows on ARM). It isn't signed yet: your browser may ask whether to keep it, and Windows says it protected your PC; choose **More info**, then **Run anyway**.
   - **macOS:** `brew install --HEAD arudaev/tap/duckwalk` builds it on your Mac, so macOS doesn't block it. Or download `duckwalk-desktop-macos-arm64` (Apple silicon) or `duckwalk-desktop-macos-x64` (Intel), run `chmod +x` on it, start it, and allow it under **System Settings > Privacy & Security > Open Anyway**. Either way it asks for **Input Monitoring**.
   - **Linux:** `duckwalk-desktop-linux-x64`; make it executable with `chmod +x`. Join the `input` group, and for USB install `70-duckwalk.rules` (also attached below).

Step by step for every system, and how to remove it: the [install guide](https://github.com/arudaev/duckwalk/blob/main/docs/install.md).

`SHA256SUMS` lists the checksum of every file here. New in this preview: GitHub keeps a signed record that each file was built by this repository's Release workflow, and from which commit. With the [GitHub CLI](https://cli.github.com/) signed in, check a file with `gh attestation verify <file> --repo arudaev/duckwalk --signer-workflow arudaev/duckwalk/.github/workflows/release.yml`. It isn't code signing: Windows and macOS still warn. Tested on Windows 11 over USB and Bluetooth; the macOS and Linux builds are untested, and [install reports](https://github.com/arudaev/duckwalk/issues/new?template=6-install-report.yml) are welcome.

## What's in it

- **Harold at his desk:** reads code, types, sips coffee, hunts bugs and quacks at them
- **Walk, Subtle and Wander** keep-awake modes
- **USB or Bluetooth**, with a connection check on the Down button
- **Settings:** how often, how far, work hours only, Stop after 1 to 8 hours
- **Remote:** media keys, slides and a D-pad mouse
- **Preview** of the next walk on the Up button

The [user guide](https://github.com/arudaev/duckwalk/blob/main/docs/guide.md) shows every screen.
