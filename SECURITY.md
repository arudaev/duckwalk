# Security policy

## Reporting a vulnerability

Please report privately through [GitHub security advisories](https://github.com/arudaev/duckwalk/security/advisories/new). Do not open a public issue. You can expect a first reply within a week.

Especially relevant:

- Ways for another program or device to send keystrokes or mouse input through Duckwalk.
- Ways to make the desktop app (once it exists) run commands it was not asked to run.
- Anything that lets the app act outside the official firmware's limits.

## Supported versions

Only the latest release and `main` receive fixes.
